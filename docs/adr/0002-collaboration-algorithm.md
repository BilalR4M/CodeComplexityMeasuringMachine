# ADR-0002: Collaboration algorithm
Status: proposed (default pending owner decision)
Context: v1 needs co-editing, chat, presence. A central relay server always exists.
Proposal: server-authoritative OT on plain-text operations, per-file rooms, presence/chat on the project room.
Alternative: CRDT (better for offline/P2P, more complexity and metadata).
Consequences: Phase 4 is blocked until this is accepted or replaced. Spike S2 validates convergence.
