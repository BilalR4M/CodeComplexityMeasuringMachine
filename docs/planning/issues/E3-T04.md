# E3-T04 Show the file outline

Labels: `agent-task`, `epic:navigation`, `size:M`, `kind:ui`

## Context
UI spec Outline. Heat and sort-by-complexity styling that needs metrics is E5-T02. This issue lists names and start lines.

## Goal
The outline lists the methods in the open Java file.

## Scope
Rows from the last AnalysisResult method list: name and start line. Click moves the caret. Non-Java: `No outline for this file`. No document: `Open a file to see its outline`.

## Out of scope
No heat bar yet. No hotspots filter yet. Those are E5-T02.

## Design
Reads the published AnalysisResult on the FX thread. Does not parse. Stale result still lists methods and E5-T08 adds the dimming; this issue shows the names either way.

## Implementation steps
1. View bound to the active document's last result.
2. Click to go to line.

## Acceptance criteria
- Given two methods, when the result is published, then both names are rows.
- Given a click on the second, when it runs, then the caret is on that start line.
- Given a markdown file, when it is active, then the text is `No outline for this file` if ADR-0010 allows it to open; otherwise the outline stays on the last Java file.

## Depends on
E1-T02, E2-T01.

## Blocks
E5-T02.

## Risks and fallbacks

Tokens only. Min 900x600.
Copy: `No outline for this file`, `Open a file to see its outline`, `Analyzing…`.
Accessibility: field placeholders are also accessible names. Ctrl bindings are Cmd on macOS.
