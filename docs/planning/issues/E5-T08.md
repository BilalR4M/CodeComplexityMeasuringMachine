# E5-T08 Keep stale metrics on the new surfaces

Labels: `agent-task`, `epic:metrics`, `size:M`, `kind:ui`

## Context
IdeWindow.publish already keeps lastGood. This issue deletes the duplicate label-only path once the new surfaces agree.

## Goal
One stale policy covers every metrics surface.

## Scope
On Failed, if lastGood exists for the same path, every surface keeps it and marks stale. If none exists, chips hide, inspector shows the parser message, status omits CC and MI.

## Out of scope
No change to Analyzer formulas.

## Design
A single MetricsSnapshot holder on the document. Surfaces read it. The old MetricsPanel labels are removed in this issue so there is not a second copy.

## Implementation steps
1. Snapshot holder.
2. Point the four surfaces at it.
3. Remove the label panel.

## Acceptance criteria
- Given a good result then a syntax error, when it publishes, then CC is unchanged on the chip and the status bar says stale.
- Given a file that never parsed, when it fails, then no chip is shown and the inspector shows the message.

## Tests
StaleSnapshotTest. Keep the existing IdeWindowTest cases, pointed at the snapshot.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E5-T01, E5-T03, E5-T04.

## Blocks
None.

## Risks and fallbacks
Removing the panel before the inspector is ready would hide metrics. The dependency order prevents that.

## UX spec
Wireframe: docs/design/wireframes/inspector.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: The word `stale` and banner `These numbers are stale`. No new sentences.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.
