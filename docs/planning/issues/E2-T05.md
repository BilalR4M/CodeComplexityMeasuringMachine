# E2-T05 Go to a line

Labels: `agent-task`, `epic:editor`, `size:S`, `kind:ui`

## Context
UI spec editor. Problems and inspector jump through this command.

## Goal
The user can jump to a line number.

## Scope
Command `go.line` titled `Go to Line…`. A small field. Enter moves the caret to that line, column 1, and scrolls it into view.

## Out of scope
No column field.

## Design
Out of range clamps to the last line and sets status `Line <n> is past the end`. Empty input does nothing. Non-digits are ignored.

## Implementation steps
1. Command and field.
2. Clamp behaviour.

## Acceptance criteria
- Given a 10-line file, when the user enters 4, then the caret is on line 4.
- Given line 99, when the file has 10 lines, then the caret is on line 10 and the status reads `Line 99 is past the end`.
