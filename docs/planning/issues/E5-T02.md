# E5-T02 Heat the outline

Labels: `agent-task`, `epic:metrics`, `size:M`, `kind:ui`

## Context
UI spec Outline. E3-T04 listed names only.

## Goal
The outline shows complexity heat and a hotspot filter.

## Scope
Heat bar using the band token. Sort Position or Complexity. Checkbox Hotspots only hides success rows.

## Out of scope
No project-wide outline.

## Design
Sort and filter run on the FX thread over the already published method list. Stale rows stay, dimmed, with the line `Outline is stale`.

## Implementation steps
1. Bind CC onto the rows from E3-T04.
2. Sort and filter.
3. Stale label.

## Acceptance criteria
- Given methods of CC 2 and CC 14, when sort is Complexity, then 14 is first.
- Given Hotspots only, when a row is success, then it is hidden.
- Given a stale result, when the view renders, then it reads `Outline is stale`.
