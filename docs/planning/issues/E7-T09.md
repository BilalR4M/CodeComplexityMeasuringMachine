# E7-T09 Export a session summary

Labels: `agent-task`, `epic:collaboration`, `size:M`, `kind:ui`

## Context
UI spec Session summary. COLLABORATION.md P1.

## Goal
The user can copy a Markdown summary of the session.

## Scope
Command `Export Session Summary`. Preview tab `Session summary` with files touched, metric deltas, open threads, resolved threads. Buttons Copy and Save. Save uses a file chooser. Nothing is sent to the relay.

## Out of scope
No automatic PR creation.

## Design
Empty: `Nothing to export yet`. Write failure: `Could not write the file`. Markdown is built off the FX thread.

## Implementation steps
1. Model.
2. Preview.
3. Copy and save.

## Acceptance criteria
- Given one file and one open thread, when export runs, then the markdown contains the path and the thread text.
- Given Copy, when it runs, then the clipboard receives that markdown and the relay client sends nothing.

## Tests
SessionSummaryTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E7-T07, E7-T08.

## Blocks
None.

## Risks and fallbacks
Do not include invite tokens or relay URLs in the markdown.

## UX spec
Wireframe: docs/design/wireframes/summary.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: `Session summary`, `Nothing to export yet`, `Copy`, `Save…`, `Could not write the file`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
