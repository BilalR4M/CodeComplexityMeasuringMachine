# E2-T07 Auto-indent the next line

Labels: `agent-task`, `epic:editor`, `size:M`, `kind:code`

## Context
Editor core. Indent is spaces, width 4, until settings grow a key. Do not add the settings key in this issue.

## Goal
Pressing Enter indents the new line.

## Scope
On Enter, insert newline plus the previous line's leading whitespace. If the previous trimmed line ends with `{`, add four spaces. All on the FX thread because it is one string insert.

## Out of scope
No format-document command. No tabs versus spaces setting.

## Design
The insert is a LOCAL edit. Remote Enter is already in the remote text and must not be indented again. Only the local key handler inserts indent.

## Implementation steps
1. Key handler.
2. Tests for plain line and brace line.

## Acceptance criteria
- Given a line `    return;`, when Enter is pressed at the end, then the next line starts with four spaces.
- Given a line `    if (ok) {`, when Enter is pressed, then the next line starts with eight spaces.
