# E7-T05 Move chat into the bottom panel

Labels: `agent-task`, `epic:collaboration`, `size:M`, `kind:ui`

## Context
ProjectRoom already stores names and chat lines. UI spec bottom panel.

## Goal
The Chat tab is a transcript.

## Scope
List of `name: text`. Field `Message`. Enter sends a chat message. No file paths are inserted by the client.

## Out of scope
No threads. Those are E7-T07. The Project / Here placeholder is removed.

## Design
Empty copy `Not sharing` when disconnected and `No messages` when connected. Send is disabled when disconnected.

## Implementation steps
1. View.
2. Send through the client.
3. Delete the old label body.

## Acceptance criteria
- Given a chat message, when it arrives, then the line is `<name>: <text>` and the tree is unchanged.
- Given no session, when the tab renders, then it reads `Not sharing`.

## Tests
ChatPanelTest. Keep ProjectRoomTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E1-T04, E7-T01.

## Blocks
None.

## Risks and fallbacks
None.

Wireframe: docs/design/wireframes/collaboration.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: `Message`, `No messages`, `Not sharing`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.
