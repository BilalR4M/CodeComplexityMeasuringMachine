# E0-T02 Compare highlighting engines

Labels: `agent-task`, `epic:spikes`, `size:M`, `kind:spike`

## Context
ADR-0009 is proposed. The fixed language set is Java, JSON, Markdown, XML, properties, and, only if ADR-0010 is accepted, JavaScript, TypeScript, and CSS.

## Goal
Pick a highlighter that stays off the JavaFX thread and inside the keystroke budget.

## Scope
Regex lexers versus a tm4e trial versus a tree-sitter binding, measured only.

## Out of scope
No dependency in ccmm-app. No grammar files shipped from this spike.

## Question
Which highlighter can restyle a 10,000-line file without breaking the 16 ms keystroke budget?

## Method
Highlight the 10,000-line Java buffer and the 5 MB file off the FX thread. Cancel a run when a newer revision arrives. Time a keystroke with highlighting enabled. Note the JDK and native libraries for tree-sitter, and the EPL obligation for tm4e.

## Metrics
docs/benchmarks/highlighting.md: highlight time, keystroke p95 with highlighting, cancel behaviour, licence note.

## Go / no-go
Go for regex lexers when the 10,000-line highlight finishes under 50 ms off-thread and keystroke p95 stays under 16 ms. A no-go names tm4e only if the owner will accept EPL-2.0, otherwise drops highlighting for the failing language. Tree-sitter wins only if it builds on JDK 21 and cannot run on the FX thread.

## Output
Note the result on ADR-0009. Do not mark it accepted. Sources under spikes/e0-t02/.

## Design
One lexer interface: List<Span> highlight(String text, String extension). The spike implements it three ways. Spans are start, end, and a token name, not a colour.

## Implementation steps
1. Implement the regex lexer for Java.
2. Time it, then a tm4e probe and a tree-sitter probe if they build.
3. Write the benchmark and the ADR note.

## Acceptance criteria
- Given a newer edit during a highlight, when the old job finishes, then its spans are discarded.
- The benchmark records times and a go or no-go.

## Tests
A unit test of the regex lexer may live in the spike module. It is not part of mvn verify.

## Verification
docs/benchmarks/highlighting.md

## Depends on
None. Interpret non-Java languages only as probes until ADR-0010 is accepted.

## Blocks
E2-T03.

## Risks and fallbacks
Tree-sitter may not have a JDK 21 build. Record the failure and do not block the regex path.
