# E4-T03 Show file icons

Labels: `agent-task`, `epic:project`, `size:M`, `kind:ui`

## Context
ADR-0014 extension map. Do not vendor icons until the ADR is accepted.

## Goal
Tree rows show an icon from the licensed set.

## Scope
The map in ADR-0014. Graphic plus accessible name that is still the file name, not the icon.

## Out of scope
No coloured product-icon theme. Git colour is E4-T04.

## Design
If ADR-0014 is not accepted, stop with Decision needed and do not copy another editor's icons. SVGs loaded once. Row height stays 24.

## Implementation steps
1. Confirm the ADR.
2. Vendor the named SVGs and the LICENSE file.
3. Cell factory.

## Acceptance criteria
- Given Foo.java, when the cell renders, then it has a graphic and the text is Foo.java.
- Given the resources, when the jar is built, then the Lucide LICENSE file is included.

## Tests
FileIconMapTest for the extension table. A cell test if the harness can see graphics.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E4-T02 and accepted ADR-0014.

## Blocks
None.

## Risks and fallbacks
Missing SVG falls back to the generic file glyph, not a crash.

## UX spec
Wireframe: docs/design/wireframes/explorer.md and docs/design/UI_SPEC.md.
Tokens only. Min 900x600.
Copy: Tooltip on a truncated name is the project-relative path.
Accessibility: field placeholders are also accessible names. Ctrl bindings are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
