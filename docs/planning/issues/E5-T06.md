# E5-T06 Add the project dashboard

Labels: `agent-task`, `epic:metrics`, `size:L`, `kind:ui`

## Context
UI spec Metrics dashboard. Analyzer.scan already walks Java files.

## Goal
A Metrics tab shows project hotspots.

## Scope
Command `Open Metrics Dashboard`. Editor tab titled Metrics. Worst 10 methods by cyclomatic complexity. File table with a heat bar. Non-Java files absent.

## Out of scope
Delta versus a base branch is E5-T07's data; this tab shows `Delta vs <branch>` only when that issue has stored a base. Until then the line is omitted.

## Design
Scan off the FX thread with latest-wins. Empty: `Open a folder to see project metrics`. Loading: `Scanning Java files…`. Failure: `Scan failed: <message>` and keep the previous table. Click a method opens the file and go.line.

## Implementation steps
1. Scan job.
2. Tab.
3. Tests with a temp project of three methods.

## Acceptance criteria
- Given three methods, when the scan finishes, then the highest CC is first and at most 10 rows show.
- Given a scan error after a success, when it returns, then the old table remains and the error line shows.

## Tests
DashboardTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E2-T02, E5-T01.

## Blocks
None.

## Risks and fallbacks
A full scan on the FX thread would miss the budget. The worker is mandatory.

## UX spec
Wireframe: docs/design/wireframes/dashboard.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: `Metrics`, `Worst methods`, `Scanning Java files…`, `Open a folder to see project metrics`, `Scan failed: <message>`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
