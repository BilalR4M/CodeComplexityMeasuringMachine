# E7-T07 Anchor comment threads

Labels: `agent-task`, `epic:collaboration`, `size:L`, `kind:ui`

## Context
ADR-0011. E0-T03 transformer. UI spec Threads. GitHub and Reviewable patterns in the survey.

## Goal
A comment can be attached to a range and resolved without being deleted.

## Scope
Message thread: id, path, start, end, author, text, open or resolved. Composer `Comment on this range` and button `Comment`. List in the Session view. A deleted range renders `Outdated — the code was removed`.

## Out of scope
No suggested edits. No GitHub sync.

## Design
Apply AnchorTransformer from E0-T03 to every thread on each text op. Viewers may comment. Viewers may not replace document text. Resolving keeps the row, dimmed.

## Implementation steps
1. Messages and transformer wiring.
2. Composer and list.
3. Tests for an insert above the range.

## Acceptance criteria
- Given a thread on offsets 10..20, when five characters are inserted at 0, then the thread is 15..25.
- Given resolve, when the list renders, then the row remains and reads Resolved.
- Given a viewer, when they send a text op, then the server or client rejects it. The client does not apply it locally as a remote echo of their own write.
