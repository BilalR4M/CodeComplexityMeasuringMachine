# E2-T01 Add a document model

Labels: `agent-task`, `epic:editor`, `size:L`, `kind:code`

## Context
docs/architecture.md Document and EditOrigin. The CodeArea remains the view.

## Goal
Open files are documents the rest of the IDE can share.

## Scope
Document with relativePath, text, dirty, replace(start, end, text, origin). LOCAL marks dirty and pushes undo. REMOTE does not mark a local undo step and does not mark dirty if the result matches the last saved text. One open document is the current IdeWindow behaviour, migrated onto this type.

## Out of scope
No tab strip (E2-T02). No highlighting. Non-Java files may be stored only if ADR-0010 is accepted; until then reject a non-.java path with status `Only Java files can be opened` and keep the API able to store any string so the later ADR is a one-line policy change.

## Design
Document.replace validates bounds and throws IllegalArgumentException to the caller, not to the scene. The workbench catches it and sets the status bar.
Paths use '/'. Windows backslashes are normalized.
Empty text is valid.
The existing AnalysisScheduler subscribes to LOCAL changes of a .java document only.
Saved snapshot is the last text written to disk or loaded from disk.

## Implementation steps
1. Add Document and unit tests without JavaFX.
2. Point IdeWindow's single buffer at it.
3. Keep RemoteEdits applying as REMOTE.

## Acceptance criteria
- Given a loaded file, when a LOCAL replace changes a character, then dirty is true.
- Given a REMOTE replace that restores the saved text, when it is applied, then dirty is false and undo does not reverse the remote edit.
- Given a non-java path while ADR-0010 is unaccepted, when open is requested, then the status bar reads `Only Java files can be opened`.

## Tests
DocumentTest, plus the existing RemoteEditsTest and IdeWindowTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
None. The non-Java policy waits on ADR-0010 for the permissive behaviour; the rejection message ships either way.

## Blocks
E2-T02, E1-T10, E5, E7-T03.

## Risks and fallbacks
Undo suspend must stay the RemoteEdits path. Do not push remote ops onto the undo stack.
