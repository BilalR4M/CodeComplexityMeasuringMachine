# E3-T06 Navigate back and forward

Labels: `agent-task`, `epic:navigation`, `size:M`, `kind:code`

## Context
Design brief navigation list.

## Goal
The user can return to the previous caret position.

## Scope
A stack of (path, offset) pushed when the caret moves more than 20 lines or changes file. Alt+Left / Alt+Right. Cap 50.

## Out of scope
No mouse back button.

## Design
Navigation caused by Back itself does not push. Follow mode (later) pushing a location does push, so Back leaves follow; E7-T04 must call the same stop. This issue exposes NavigationHistory.record and .back.

## Implementation steps
1. History.
2. Key bindings.
3. Tests.

## Acceptance criteria
- Given a jump from line 1 to line 40, when Alt+Left is pressed, then the caret returns to line 1.
- Given Back, when it runs, then it does not add another entry.

## Tests
NavigationHistoryTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E2-T05.

## Blocks
E7-T04 uses it.

## Risks and fallbacks
Recording every arrow key will fill the stack. The 20-line threshold is the guard.
