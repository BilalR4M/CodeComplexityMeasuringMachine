# E8-T04 Add onboarding hints

Labels: `agent-task`, `epic:polish`, `size:S`, `kind:ui`

## Context
E8 polish. One hint, not a tour.

## Goal
The first analyzed Java file explains the gutter chip.

## Scope
A single hint `This number is cyclomatic complexity. Click it for the method.` with `Dismiss`. Dismiss persists in settings key hint.complexity=off.

## Out of scope
No multi-step tour. No network.

## Design
Shown once per settings file. Does not steal focus. Escape dismisses.

## Implementation steps
1. Hint.
2. Persist dismissal.
3. Test.

## Acceptance criteria
- Given a fresh settings file and a Java result, when the chip appears, then the hint is shown.
- Given Dismiss, when the next file opens, then the hint is absent.

## Tests
OnboardingHintTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E3-T08, E5-T01.

## Blocks
None.

## Risks and fallbacks
Do not show it on every file.

## UX spec
Wireframe: docs/design/wireframes/editor.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: `This number is cyclomatic complexity. Click it for the method.`, `Dismiss`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
