# E1-T06 Add a command registry

Labels: `agent-task`, `epic:workbench`, `size:M`, `kind:code`

## Context
docs/architecture.md Command interface.

## Goal
Features register commands instead of adding menu handlers.

## Scope
CommandRegistry with id, title, and run(Workbench). Register the existing open-directory action as `file.open` titled `Open Folder…`.

## Out of scope
No palette UI (E3-T02). No keymap file yet (E1-T07).

## Design
public record CommandId(String value) {}
public interface Command { String id(); String title(); void run(Workbench workbench); }
Registry rejects a duplicate id. execute(id) runs on the FX thread and throws no exception to the scene: a command failure sets the status bar to the command's message.
Open Folder uses the existing DirectoryChooser.

## Implementation steps
1. Add the registry.
2. Move the menu item onto file.open.
3. Test duplicate rejection and a successful open.

## Acceptance criteria
- Given two commands with id file.open, when the second is registered, then registration fails.
- Given file.open, when it is executed with a chosen folder, then the tree lists that folder.
