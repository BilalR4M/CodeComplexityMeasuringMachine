# E2-T04 Find and replace in the buffer

Labels: `agent-task`, `epic:editor`, `size:M`, `kind:ui`

## Context
UI spec editor shortcuts. Search across files is E3-T03.

## Goal
The open document can be searched and replaced.

## Scope
Find bar: query, next, previous, match case. Replace bar adds replacement and Replace. Replace All asks nothing inside one file but shows `Replaced <n>` in the status bar.

## Out of scope
No regex. No project search.

## Design
Search runs on ccmm-analysis or a dedicated finder thread for documents over 1 MiB; smaller files may run on FX if a test shows it is under 16 ms. Start with off-thread always. Wrap from the end. Empty query shows no matches and does not select all.

## Implementation steps
1. Finder that returns offsets.
2. Find bar.
3. Replace as LOCAL edits, one undo step for Replace All.

## Acceptance criteria
- Given `parse` twice, when Next is pressed twice, then the second match is selected.
- Given Replace All of `a` with `b` in `a a`, when it runs, then the text is `b b`, dirty is true, and one undo restores `a a`.

## Tests
FindReplaceTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E2-T01, E1-T07.

## Blocks
None.

## Risks and fallbacks
Replace All on a remote-followed view still counts as LOCAL and stops follow (E7-T04).

## UX spec
Wireframe: docs/design/wireframes/editor.md. Section in docs/design/UI_SPEC.md.
Visuals: tokens only. 900x600 minimum.
Copy: Find field accessible name `Find`, replace `Replace`, status `Replaced <n>`, `No matches`.
Accessibility: icon buttons expose the tooltip as the accessible name. Keyboard shortcuts use Ctrl, and Cmd on macOS via the keymap.
