# E1-T10 Restore the session

Labels: `agent-task`, `epic:workbench`, `size:M`, `kind:code`

## Context
UI spec welcome and workbench. Document model is E2-T01.

## Goal
The next launch reopens the last folder and the pinned documents.

## Scope
session.properties beside settings: lastFolder, pinned paths separated by newline, sideBarVisible, bottomVisible, inspectorVisible. Ignore a path that no longer exists.

## Out of scope
No restore of caret per file in this issue. No restore of unsaved buffers; those prompt on close via E2-T02.

## Design
Load after the stage is shown, off the FX thread for the existence checks, then open on the FX thread. A missing folder shows the welcome state and does not throw. Cap pinned paths at 20.

## Implementation steps
1. Write session on close and on pin changes.
2. Restore on start.
3. Test a missing path.

## Acceptance criteria
- Given a saved folder and two pinned paths, when the workbench starts, then those files open.
- Given a deleted folder, when the workbench starts, then the welcome view shows and no exception is thrown.

## Tests
SessionRestoreTest using a temp config dir.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E1-T09, E2-T01.

## Blocks
None.

## Risks and fallbacks
Restoring a huge file. E2-T09's large-file mode applies if the file exceeds the threshold.
