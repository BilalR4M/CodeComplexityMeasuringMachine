# E6-T02 Add the output panel

Labels: `agent-task`, `epic:run`, `size:M`, `kind:ui`

## Context
UI spec bottom panel. Local processes only.

## Goal
The Output tab shows task stdout and stderr.

## Scope
Command `Run Task…` lists parsed tasks. The process starts off the FX thread. Lines append in batches of at most 50 ms. Cancel kills the process.

## Out of scope
No shared terminal. No network. The working directory stays inside the project.

## Design
A task with a rejected path never starts. Non-zero exit sets status `Task <name> exited <code>`. The panel copy when idle is `No output`.

## Implementation steps
1. Output tab.
2. Process runner with a fake in tests.
3. Cancel.

## Acceptance criteria
- Given a fake process that prints hi, when the task runs, then the tab contains hi.
- Given Cancel, when it runs, then the process is destroyed.
- Given a directory outside the root, when run is attempted, then no process starts.
