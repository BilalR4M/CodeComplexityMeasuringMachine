# E1-T04 Add the bottom panel shell

Labels: `agent-task`, `epic:workbench`, `size:M`, `kind:ui`

## Context
UI spec bottom panel. Terminal exists only if the owner keeps E6.

## Goal
A collapsible bottom panel with tabs.

## Scope
Tabs Problems, Metrics, Chat. Terminal tab is created by E6-T03, not here. Each tab shows its empty copy.

## Out of scope
No gate execution and no chat connection.

## Design
BottomPanel height default 180, min 80. Ctrl+J toggles it. Tabs use token surface-2. Empty copy: Problems `No problems`, Metrics `Open a folder to see project metrics`, Chat `Not sharing`.

## Implementation steps
1. Add the panel and three tabs.
2. Wire Ctrl+J.

## Acceptance criteria
- Given Ctrl+J, when the panel is open, then it collapses.
- Given the Problems tab, when there are no diagnostics, then the text is `No problems`.

## Tests
BottomPanelTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E1-T01.

## Blocks
E5-T05, E5-T06's panel link, E6-T02, E7-T05.

## Risks and fallbacks
E6 may be dropped. Do not add a Terminal tab in this issue.

## UX spec
Wireframe: docs/design/wireframes/problems.md and the matching section of docs/design/UI_SPEC.md.
States: empty, populated.
Visuals: token names from docs/design/TOKENS.md only. Minimum window 900x600. Hit target at least 24.
Copy: `No problems`, `Open a folder to see project metrics`, `Not sharing`.
Accessibility: every icon-only control has an accessible name equal to its tooltip. Contrast uses the token ratios.

If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
