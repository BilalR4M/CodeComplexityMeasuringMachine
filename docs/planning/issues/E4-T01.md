# E4-T01 Apply ignore rules

Labels: `agent-task`, `epic:project`, `size:M`, `kind:code`

## Context
Assessment FileNode.read. Design brief project section.

## Goal
Directory listings skip ignored names.

## Scope
IgnoreRules. Defaults always: .git, .hg, .svn, node_modules, .next, .tmp, target, build, dist, .idea. Plus gitignore patterns from each directory's .gitignore, including a top-level one. `!` negations are in scope. `**` is in scope. A line that is not a valid pattern is skipped.

## Out of scope
No UI dimming of ignored files; they are absent. Git status is E4-T04.

## Design
public final class IgnoreRules {
  public static IgnoreRules load(Path root);
  public boolean ignores(Path relative);
}
Load off the FX thread. Relative paths use '/'.
Do not follow a directory that is ignored. The caller (today's eager tree, tomorrow's lazy list) checks before recursing.
Tests use a temp tree, not heliogrid.

## Implementation steps
1. Parser tests for gitignore lines.
2. Wire FileNode.read to skip ignored directories.
3. Keep the eager walk until E4-T02, but it must not enter ignored dirs.

## Acceptance criteria
- Given a .gitignore of `node_modules/`, when the tree is built, then node_modules is absent and its children were not listed.
- Given a negation `!keep.log` under `*.log`, when the tree is built, then keep.log is present.
