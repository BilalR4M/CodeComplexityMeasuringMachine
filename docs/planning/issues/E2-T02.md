# E2-T02 Add a tab strip

Labels: `agent-task`, `epic:editor`, `size:L`, `kind:ui`

## Context
UI spec Tabs. ISSUE_SPEC worked example. docs/design/wireframes/tabs.md.

## Goal
Open files appear as tabs, with one preview tab and a dirty marker.

## Scope
TabStrip over the document list. Single click in the tree opens a preview (italic) that the next single click replaces. Double click or a LOCAL edit pins it. Middle click and Ctrl+W close. Ctrl+Shift+T reopens the last of 20. Overflow scrolls and a chevron lists `Open tabs`.

## Out of scope
No split editors. No drag-reorder in this issue.

## Design
Dirty shows a dot and accessible name `<name>, unsaved`.
Closing dirty asks `Save changes to <name>?` with Save, Don't Save, Cancel.
Save writes UTF-8 and clears dirty. IOException sets status `Could not save <name>` and leaves dirty true.
Preview is not written to the session pin list.

## Implementation steps
1. Tab model and preview rules.
2. Close prompt.
3. Reopen stack.

## Acceptance criteria
- Given a preview tab, when another file is single-clicked, then the preview is replaced.
- Given a dirty tab, when it is closed and Cancel is chosen, then the tab stays.
- Given 40 tabs in a narrow window, when they overflow, then a control labelled `Open tabs` lists them.

## UX spec
Wireframe: docs/design/wireframes/tabs.md. Section in docs/design/UI_SPEC.md.
Visuals: tokens only. 900x600 minimum.
Copy: `Save changes to <name>?`, `Save`, `Don't Save`, `Cancel`, `Open tabs`, `<name>, unsaved`.
Accessibility: icon buttons expose the tooltip as the accessible name. Keyboard shortcuts use Ctrl, and Cmd on macOS via the keymap.
