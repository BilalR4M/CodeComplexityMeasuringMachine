# E6-T01 Define build and run tasks

Labels: `agent-task`, `epic:run`, `size:M`, `kind:code`

## Context
PLAN.md non-goal running code. Open decision: the owner may strike E6.

## Goal
Projects can declare a named task.

## Scope
`.ccmm/tasks.properties` optional file: name, command, working directory relative to the root. Parser only. No process is started.

## Out of scope
No terminal. No arbitrary code from the relay. A peer cannot send a task.

## Design
Reject a working directory that leaves the root. Reject an empty command. Missing file yields an empty list, not an error.

## Implementation steps
1. Parser.
2. Tests for escape and a valid file.
3. Do not spawn a process.

## Acceptance criteria
- Given a command and a directory `..`, when parsed, then the task is rejected.
- Given a valid file, when loaded, then the name and command are kept and no process exists.
