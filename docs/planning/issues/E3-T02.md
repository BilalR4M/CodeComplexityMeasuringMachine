# E3-T02 Add the command palette

Labels: `agent-task`, `epic:navigation`, `size:M`, `kind:ui`

## Context
UI spec Command palette. Registry from E1-T06.

## Goal
The palette lists commands and runs the chosen one.

## Scope
Popup placeholder `Type a command`. Rows are title and shortcut. Empty query shows recently used (max 10) then the rest. Substring match on the title.

## Out of scope
No fuzzy ranker beyond substring. No command creation.

## Design
The list reads CommandRegistry. Enter calls execute. A command that sets the status string still closes the palette. `No matching commands` when the filter is empty.

## Implementation steps
1. Palette view.
2. Recent list in memory only.
3. Tests.

## Acceptance criteria
- Given a query `open`, when Open Folder is registered, then that row is visible and Enter runs it.
- Given a query with no match, then the text is `No matching commands`.
