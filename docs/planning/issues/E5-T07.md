# E5-T07 Run a pre-flight gate

Labels: `agent-task`, `epic:metrics`, `size:M`, `kind:ui`

## Context
Design brief pre-flight. This issue does not commit or push.

## Goal
A command lists changed methods that cross a threshold.

## Scope
Command `Pre-flight Gate` uses git diff against the branch named in settings key baseBranch, default main. Reuse the CLI's changed-file selection if it can be called without a process exit. Show rows in Problems.

## Out of scope
No commit, no push, no .ccmm.yml added to this repo.

## Design
Off the FX thread. Exit-style result is a list, not System.exit. No git repo: status `no git`. Clean tree: status `No changed Java methods`.

## Implementation steps
1. Call the gate library API.
2. Render rows.
3. Tests with a temp git repo.

## Acceptance criteria
- Given a changed method over the limit, when the command runs, then Problems shows the same message the CLI would print.
- Given no .git, when it runs, then the status is `no git` and git is not written.

## Tests
PreflightGateTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E5-T05, E4-T04.

## Blocks
None.

## Risks and fallbacks
Do not shell out to git commit. Read-only git commands only.

## UX spec
Wireframe: docs/design/wireframes/problems.md and docs/design/UI_SPEC.md.

Copy: `Pre-flight Gate`, `No changed Java methods`, `no git`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.
