# E3-T05 Show breadcrumbs

Labels: `agent-task`, `epic:navigation`, `size:S`, `kind:ui`

## Context
Design brief layout: `src > app > Foo > parse()`.

## Goal
A breadcrumb row shows where the caret is.

## Scope
Segments of the relative path plus the method name from MetricsPanel.methodAt when the result is Java. Click a path segment reveals that folder in the explorer.

## Out of scope
No method dropdown.

## Design
Separator is ` > `. A non-Java file omits the method segment. Updates on caret move on the FX thread using the last result only.

## Implementation steps
1. Row.
2. Bind path and method.
3. Click selects the tree folder.

## Acceptance criteria
- Given src/app/Foo.java and the caret in parse, when the result is fresh, then the row contains `src > app > Foo.java > parse`.

## Tests
BreadcrumbTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E2-T02, E3-T04.

## Blocks
None.

## Risks and fallbacks
None.

## UX spec
Wireframe: docs/design/wireframes/editor.md and docs/design/UI_SPEC.md.
Tokens only. Min 900x600.
Copy: Segments separated by ` > `. No extra sentences.
Accessibility: field placeholders are also accessible names. Ctrl bindings are Cmd on macOS.
