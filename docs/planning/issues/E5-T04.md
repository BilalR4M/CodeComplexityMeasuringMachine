# E5-T04 Show metrics in the status bar

Labels: `agent-task`, `epic:metrics`, `size:S`, `kind:ui`

## Context
UI spec status bar.

## Goal
Caret metrics sit in the status bar.

## Scope
When the caret is inside a method, show `CC <n>` and `MI <n>` with one decimal for MI using Locale.US. Click CC shows the inspector. Stale appends `stale` in the warn token.

## Out of scope
No online count. That is E7.

## Design
Updates on caret move from the last result only. No new analysis. Outside a method, omit CC and MI.

## Implementation steps
1. Bind the slots.
2. Click command.
3. Stale word.

## Acceptance criteria
- Given a method with CC 7 and MI 64.2, when the caret is inside it, then the bar contains `CC 7` and `MI 64.2`.
- Given a stale result, when the bar renders, then it contains `stale` and the tooltip is `Showing the last successful analysis`.
