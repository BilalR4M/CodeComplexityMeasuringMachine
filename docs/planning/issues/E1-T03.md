# E1-T03 Add the side bar shell

Labels: `agent-task`, `epic:workbench`, `size:S`, `kind:ui`

## Context
UI spec explorer and workbench. E1-T02 created the views.

## Goal
The side bar has a title row and a collapse button.

## Scope
Title label bound to the active view. Collapse button hides the side bar. Ctrl+B restores it.

## Out of scope
No file operations.

## Design
SideBar title is the view name: Explorer, Search, Outline, Session, Settings. Collapse button accessible name `Hide side bar`. Width persists for the session only; E1-T10 persists it later.

## Implementation steps
1. Add the title and button.
2. Bind them to the active view.

## Acceptance criteria
- Given the Search view, when it is active, then the title is Search.
- Given Ctrl+B, when it is pressed, then the side bar hides and a second press shows it.

## Tests
SideBarTest.

mvn -B -ntp -pl ccmm-app -am test

## Depends on
E1-T02.

## Blocks
None.

## Risks and fallbacks

Wireframe: docs/design/wireframes/explorer.md and the matching section of docs/design/UI_SPEC.md.
States: populated, empty.
Visuals: token names from docs/design/TOKENS.md only. Minimum window 900x600. Hit target at least 24.

Accessibility: every icon-only control has an accessible name equal to its tooltip. Contrast uses the token ratios.
