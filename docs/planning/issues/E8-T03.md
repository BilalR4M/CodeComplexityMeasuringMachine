# E8-T03 Audit empty and error copy

Labels: `agent-task`, `epic:polish`, `size:S`, `kind:ui`

## Context
docs/design/UI_SPEC.md copy lines.

## Goal
Empty and error states use the specified sentences.

## Scope
A table of required strings. Fix mismatches. Do not invent new wording.

## Out of scope
No new features.

## Design
UiCopyTest holds the strings. Views expose text for the test the same way MetricsPanel.text does.

## Implementation steps
1. Table from the spec.
2. Fix drifts.
3. Test.

## Acceptance criteria
- Given each required sentence in the table, when the matching state is shown, then the text contains that sentence.

## Tests
UiCopyTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E3-T08, E5-T05, E7-T01.

## Blocks
None.

## Risks and fallbacks
Later issues can add strings. This test should include only the sentences already shipped, and the PR lists any spec line whose issue is still open.

## UX spec
Wireframe: docs/design/wireframes/welcome.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: Use the spec sentences. Do not paraphrase them in the product.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
