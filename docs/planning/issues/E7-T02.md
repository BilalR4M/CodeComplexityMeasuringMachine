# E7-T02 Compare file hashes on join

Labels: `agent-task`, `epic:collaboration`, `size:M`, `kind:code`

## Context
ADR-0011 option C. New message types are a protocol change already specified here.

## Goal
Joining compares a content hash of each open file.

## Scope
Message type hash: path, sha-256 of UTF-8 text. Host sends hashes for its open files. Guest compares. Mismatch opens a read-only diff and buttons `Use host version` and `Keep mine`.

## Out of scope
No automatic overwrite. No tree sync.

## Design
Path checks from P4-T02 apply. Hashing runs off the FX thread. Use host version is a LOCAL replace of the whole buffer and marks dirty. Keep mine sends nothing.

## Implementation steps
1. Codec tests for the new type.
2. UI prompt.
3. Apply host text.

## Acceptance criteria
- Given different bytes, when the hash arrives, then the prompt is shown and the buffer is unchanged.
- Given Use host version, when it is clicked, then the buffer equals the host text and dirty is true.
- Given a path with `..`, when a hash arrives, then it is ignored.
