# E7-T11 Hide ignored and secret files from guests

Labels: `agent-task`, `epic:collaboration`, `size:M`, `kind:code`

## Context
COLLABORATION.md security. Live Share pattern in the survey. Ignore rules from E4-T01.

## Goal
The host does not share ignored or secret files.

## Scope
Refuse hash, text, and thread messages whose path is ignored or matches `.env`, `.env.*`, `*.pem`, `*.key`, `id_rsa`, `id_ed25519`. The guest UI says `This file is not shared`.

## Out of scope
No scanning of file contents for secrets. Names only.

## Design
The check runs on the host before send and on the server as a second line using the path pattern, not the host's gitignore file, for the secret names. Gitignore itself is enforced on the host because the server does not have the file. Both are tested.

## Implementation steps
1. Secret name matcher.
2. Host filter using IgnoreRules.
3. Server filter for the secret names.

## Acceptance criteria
- Given `.env`, when a guest requests it, then no bytes are sent and the guest sees `This file is not shared`.
- Given a gitignored path, when the host would send a hash, then it does not.

## Tests
SecretPathTest, GuestHideTest.

## Verification
mvn -B -ntp -pl ccmm-collab-server,ccmm-app -am test

## Depends on
E4-T01, E7-T10.

## Blocks
None.

## Risks and fallbacks
A custom secret name will be missed. The list above is the contract. Document it in the session view tooltip `Secret and ignored files are not shared`.
