# E5-T05 List gate violations as problems

Labels: `agent-task`, `epic:metrics`, `size:L`, `kind:ui`

## Context
UI spec Problems. Gate rules already live for the CLI. Do not fork the threshold parser. If the parser is private to ccmm-cli, move the rule model to ccmm-core in this issue without changing CLI output.

## Goal
The Problems tab lists parse failures and gate violations.

## Scope
Rows for the open Java file on each analysis, plus a command `Check Project` that runs the same rules as the CLI over Java files, off the FX thread. Missing .ccmm.yml uses defaults and one status line `No .ccmm.yml — using the default thresholds`.

## Out of scope
No GitHub comment posting.

## Design
Message copy: `Cyclomatic complexity <n> exceeds <limit>`, `Nesting <n> exceeds <limit>`, `Maintainability <n> is below <limit>`, `Could not parse: <message>`. Click calls go.line. Cap is not required for one file. Project check lists path:line.

## Implementation steps
1. Share the rule loader.
2. Map one file's result to rows.
3. Project command.

## Acceptance criteria
- Given cyclomatic 14 and limit 10, when analysis publishes, then Problems contains `Cyclomatic complexity 14 exceeds 10`.
- Given a click, when it runs, then the caret is on that line.
- Given no .ccmm.yml, when Check Project runs, then the status is `No .ccmm.yml — using the default thresholds` and the process does not throw.

## Tests
ProblemsModelTest. A CLI test that the moved loader still parses the sample file.

## Verification
mvn -B -ntp -pl ccmm-cli,ccmm-app -am test

## Depends on
E1-T04, E2-T05.

## Blocks
E5-T07.

## Risks and fallbacks
Moving the loader is a public API if it leaves ccmm-cli. Prefer ccmm-core and stop with Decision needed if that export is controversial. The issue text is the request; the owner already asked for this plan.

## UX spec
Wireframe: docs/design/wireframes/problems.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: `No problems`, `Checking…`, `Cyclomatic complexity 14 exceeds 10`, `Could not parse: <message>`, `No .ccmm.yml — using the default thresholds`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
