# E8-T02 Check high DPI and the latency budgets

Labels: `agent-task`, `epic:polish`, `size:M`, `kind:ui`

## Context
Budgets in PLAN.md. E0-T04 and E4-T02 notes.

## Goal
The integrated window still meets the budgets.

## Scope
Re-run keystroke, cold start, and the lazy-tree fixture. Record OS and scale 100 and 150 percent for a screenshot pair. No new features.

## Out of scope
No budget changes. A miss is a no-go note, not a quiet edit to the budget.

## Design
Use the existing harnesses pointed at the workbench. Append sections. Do not delete the old numbers.

## Implementation steps
1. Run the harnesses.
2. Append results.
3. If a budget misses, file the cause in the note and stop.

## Acceptance criteria
- Given the product window, when the keystroke harness runs, then a new p95 is in keystroke-latency.md.
- Given a miss of 16 ms, when the file is written, then it says no-go and does not change the budget line in PLAN.md.

## Tests
Existing benchmark file tests stay green if they only check the original decision block. Extend them only if they require a single trailing go.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Blocks

## Risks and fallbacks
