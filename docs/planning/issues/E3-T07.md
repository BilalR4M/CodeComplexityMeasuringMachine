# E3-T07 Remember recent files and projects

Labels: `agent-task`, `epic:navigation`, `size:M`, `kind:code`

## Context
UI spec Welcome and Quick open.

## Goal
Recent projects and files are stored.

## Scope
Append to the config directory: recent-projects.txt and recent-files.txt, most recent first, caps 10 and 20. A missing path stays in the list with a flag the welcome view renders as `Folder missing`.

## Out of scope
The welcome layout is E3-T08. This issue is the store and a package-visible reader.

## Design
Writes use temp-file-and-move. Duplicates move to the top. Paths are absolute on disk and are not sent to the relay.

## Implementation steps
1. Store.
2. Hook folder open and file pin.
3. Tests.

## Acceptance criteria
- Given two projects opened in order, when the list is read, then the second is first.
- Given a deleted path, when it is read, then it is still listed and marked missing.

## Tests
RecentStoreTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E1-T09.

## Blocks
E3-T08, E3-T01's empty-query recents.

## Risks and fallbacks
Do not store file contents.
