# E4-T06 Reveal a file in the operating system

Labels: `agent-task`, `epic:project`, `size:S`, `kind:code`

## Context
Design brief. Desktop.getDesktop() or the OS open command.

## Goal
Reveal in File Manager shows the selected file's folder.

## Scope
Command `Reveal in File Manager`. Windows explorer /select, macOS open -R, other xdg-open on the parent. Failure sets status `Could not reveal <name>`.

## Out of scope
No custom file dialog.

## Design
Do not reveal a path outside the project. The process starts off the FX thread.

## Implementation steps
1. Command.
2. A test that the argument list is correct per OS, using a fake launcher, not a real explorer window.

## Acceptance criteria
- Given Windows, when reveal is built for a file, then the command includes explorer and /select.
- Given a path outside the root, when reveal is called, then no process starts.

## Tests
RevealCommandTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E4-T02.

## Blocks
None.

## Risks and fallbacks
CI has no desktop. Do not launch a real file manager in the test.
