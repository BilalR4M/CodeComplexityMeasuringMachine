# E3-T08 Add the welcome screen

Labels: `agent-task`, `epic:navigation`, `size:M`, `kind:ui`

## Context
UI spec Welcome. Start a Session runs the E7 command if present, otherwise status `Command is not available yet` from the keymap rule... better: the button is disabled with tooltip `Sessions arrive in a later change` until E7-T01 registers `session.start`.

## Goal
Startup with no folder shows a welcome view.

## Scope
Heading `CCMM IDE`, buttons `Open Folder…` and `Start a Session…`, shortcut lines, recent list.

## Out of scope
No session implementation.

## Design
Shown when no folder is open. Command `Show Welcome` titled that. A missing recent shows `Folder missing` and does not throw on click; click sets status `Folder missing`.

## Implementation steps
1. View.
2. Bind recents.
3. Commands.

## Acceptance criteria
- Given no folder, when the stage shows, then `Open Folder…` is visible.
- Given a missing recent, when it is clicked, then the status is `Folder missing`.

## Tests
WelcomeViewTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E3-T07, E1-T06.

## Blocks
None.

## Risks and fallbacks
Start a Session must not throw if E7 is absent.

## UX spec
Wireframe: docs/design/wireframes/welcome.md and docs/design/UI_SPEC.md.
Tokens only. Min 900x600.
Copy: `CCMM IDE`, `Open Folder…`, `Start a Session…`, `Recent`, `Folder missing`, `Ctrl+P Quick open`, `Ctrl+Shift+P Commands`, `Ctrl+Shift+F Search`.
Accessibility: field placeholders are also accessible names. Ctrl bindings are Cmd on macOS.

## Evidence required in the PR
Screenshots: dark and light, 100% and 150% scale. A short GIF when the interaction is more than a click. If the change runs on a keystroke, record that the JavaFX thread work stayed inside the 16 ms p95 budget in `docs/benchmarks/keystroke-latency.md` or say why this change does not run on a keystroke.
