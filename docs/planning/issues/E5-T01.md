# E5-T01 Show gutter complexity chips

Labels: `agent-task`, `epic:metrics`, `size:L`, `kind:ui`

## Context
docs/architecture.md GutterChip. docs/design/TOKENS.md metric bands. MetricsPanel.methodAt already picks the method.

## Goal
Method signatures show a complexity chip in the gutter.

## Scope
After a fresh or stale AnalysisResult, place one GutterChip at each method startLine. Band from .ccmm.yml or the defaults in TOKENS.md (cyclomatic 10, nesting 3, maintainability 20). Click runs command inspector.show.

## Out of scope
No decision-point list. That is the inspector. No second parser.

## Design
Chips are built off the FX thread from the result, applied in one FX update. Stale sets the chip stale flag and 50 percent opacity. A file that has never parsed shows no chips. Large-file mode shows no chips. Colour is the token name on the decoration, styled by the theme.

## Implementation steps
1. Band function with tests.
2. Decorations on the editor from E0-T01.
3. Click opens the inspector region.

## Acceptance criteria
- Given a method with cyclomatic 14 and threshold 10, when the result is published, then the chip text is 14 and the band is danger.
- Given a parse failure after a good result, when it is published, then the chips remain and are stale.
- Given a click, when it runs, then the inspector region is visible.

## Tests
MetricBandTest, GutterChipTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E2-T01, E0-T01 go.

## Blocks
E5-T03, E7-T06's method badge.

## Risks and fallbacks
If the bake-off cannot draw a side decoration, stop with Decision needed and do not fake chips in the text.

## UX spec
Wireframe: docs/design/wireframes/editor.md and docs/design/UI_SPEC.md.
Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: Chip accessible name `Cyclomatic complexity <n>`. Tooltip `Open inspector`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.
