# E7-T08 Show the session metrics lens

Labels: `agent-task`, `epic:collaboration`, `size:M`, `kind:ui`

## Context
COLLABORATION.md shared metrics lens.

## Goal
Everyone in the session sees how complexity moved.

## Scope
On join, snapshot CC per open Java method. On each local publish, update a line `+<n> CC across <m> methods since start` or the negative form. Gate row uses the same Passes or Breaks text as the inspector.

## Out of scope
No per-keystroke network of metrics. Send at most one metrics summary per second.

## Design
The summary is a new message metrics-delta. Peers who miss it catch up on the next tick. A stale local result is not sent.

## Implementation steps
1. Snapshot.
2. Message at 1 s cadence.
3. Label.

## Acceptance criteria
- Given CC moves from 7 to 10 on one method, when the summary is sent, then the text is `+3 CC across 1 method since start`.
- Given a stale result, when the timer fires, then no metrics message is sent.

## Tests
MetricsLensTest.

## Verification
mvn -B -ntp -pl ccmm-app -am test

## Depends on
E5-T08, E7-T01.

## Blocks

## Risks and fallbacks
Do not flood the relay. The one-second cap is the test.

## UX spec

Tokens only. Minimum window 900x600. Hit target at least 24.
Copy: `+3 CC across 1 method since start`, `+3 CC across 2 methods since start`, `-1 CC across 1 method since start`.
Accessibility: icon-only controls use the tooltip as the accessible name. Ctrl shortcuts are Cmd on macOS.
